# Оплаты СберБизнес → сайт (личный кабинет)

Сайт узнаёт об оплате счёта двумя путями. Достаточно любого, можно оба: дубли отсекаются.

| Контур | Как | Кто настраивает |
|---|---|---|
| **А. Вебхук из 1С:УНФ** (основной) | 1С загружает выписку из СберБизнеса (DirectBank) и при проведении «Поступления на счёт» отправляет POST на сайт | программист 1С, расширение ниже |
| **В. Выписка вручную** (резервный) | менеджер выгружает выписку из СберБизнеса в формате 1С (.txt) и загружает в /lk/admin/ → «Оплаты Сбербанк» | менеджер, без настроек |
| Б. Прямой API Сбера (Fintech API) | — | отложено: нужен договор на API и сертификаты |
| QR СБП | — | отложено: нужен договор эквайринга |

## Как сайт находит заказ

1. Номер заказа сайта в назначении платежа: `ИТ-261114-3` (допускается `IT`, пробелы, без дефиса).
2. Номер и дата счёта из 1С: «Оплата по счёту № 125 от 14.11.2026». Менеджер вводит номер, дату и сумму, когда загружает PDF счёта в карточку заказа.
3. Поля `order` или `invoice_number` из вебхука, если 1С их передаёт (надёжнее всего).

Платёж разносится автоматически, только если найден ровно один открытый заказ и ИНН плательщика совпадает с ИНН заказа или компании клиента.
Иначе платёж попадает в «Неразнесённые оплаты», где менеджер привязывает его в 1 клик.

Если сумма меньше счёта, заказ получает статус «Частично оплачен» и клиент видит остаток. Полная оплата даёт «Оплачен»: продлевается услуга (аренда, сопровождение), снимается срок резерва, клиенту уходит письмо.
В Telegram менеджеру идёт только номер заказа и сумма, без данных плательщика.

## Контур А: вебхук

```
POST https://pbk.spb.ru/api/v1/payments/callback
Content-Type: application/json
X-Timestamp: 1763112000              ← Unix-время, секунды (расхождение не больше 10 минут)
X-Signature: 3f1c…e9                 ← hex(HMAC-SHA256(секрет, X-Timestamp + "." + тело))

{
  "order": "ИТ-261114-3",            ← необязательно
  "invoice_number": "125",           ← необязательно
  "invoice_date": "14.11.2026",      ← необязательно
  "amount": 48000.00,                ← обязательно
  "payment_date": "14.11.2026",
  "payment_order_num": "742",        ← обязательно (номер п/п)
  "payer_inn": "7801234567",
  "payer_name": "ООО «Ромашка»",
  "purpose": "Оплата по счёту № 125 от 14.11.2026 за … Без НДС"
}
```

Ответ `200 {"ok":true,"status":"matched","order":"ИТ-261114-3","order_status":"Оплачен"}`.
Возможные `status`: `matched` (разнесён), `unmatched` (ждёт менеджера), `duplicate` (уже получен), `ignored`.
Ошибки: `401` — подпись или время, `400/422` — данные, `503` — секрет не настроен на сервере.

**Секрет** создаёт `server/lk-setup.sh` в `app/config.php` (`payments_secret`). Посмотреть его на сервере:
`sudo grep payments_secret /var/www/pbk.spb.ru/app/config.php`.
Секрет вносится только в константу или регистр расширения 1С. Не пересылайте его в почту или мессенджеры.

## Пример для расширения 1С:УНФ

Подписка на событие «ПриЗаписи» (или обработчик проведения) документа `ПоступлениеНаСчет`. Код в общем модуле, выполняется на сервере:

```bsl
Процедура ОтправитьОплатуНаСайт(Документ) Экспорт
	Если Документ.ВидОперации <> Перечисления.ВидыОперацийПоступлениеНаСчет.ОтПокупателя Тогда Возврат; КонецЕсли;

	Данные = Новый Структура;
	Данные.Вставить("amount", Документ.СуммаДокумента);
	Данные.Вставить("payment_date", Формат(Документ.Дата, "ДФ=dd.MM.yyyy"));
	Данные.Вставить("payment_order_num", СокрЛП(Документ.НомерВходящегоДокумента));
	Данные.Вставить("payer_inn", СокрЛП(Документ.Контрагент.ИНН));
	Данные.Вставить("payer_name", СокрЛП(Документ.Контрагент.НаименованиеПолное));
	Данные.Вставить("purpose", СокрЛП(Документ.НазначениеПлатежа));
	// Если в табличной части указан счёт на оплату:
	Для Каждого Стр Из Документ.РасшифровкаПлатежа Цикл
		Если ЗначениеЗаполнено(Стр.Документ) И ТипЗнч(Стр.Документ) = Тип("ДокументСсылка.СчетНаОплату") Тогда
			Данные.Вставить("invoice_number", СокрЛП(Стр.Документ.Номер));
			Данные.Вставить("invoice_date", Формат(Стр.Документ.Дата, "ДФ=dd.MM.yyyy"));
			Прервать;
		КонецЕсли;
	КонецЦикла;

	Запись = Новый ЗаписьJSON; Запись.УстановитьСтроку();
	ЗаписатьJSON(Запись, Данные);
	Тело = Запись.Закрыть();
	Время = Формат(УниверсальноеВремя(ТекущаяДатаСеанса()) - Дата(1970, 1, 1), "ЧГ=0");

	Секрет = ПолучитьДвоичныеДанныеИзСтроки(Константы.ИнфотехСекретВебхукаОплат.Получить(), КодировкаТекста.UTF8);
	Подпись = НРег(ПолучитьHexСтрокуИзДвоичныхДанных(
		HMAC_SHA256(Секрет, ПолучитьДвоичныеДанныеИзСтроки(Время + "." + Тело, КодировкаТекста.UTF8))));

	Заголовки = Новый Соответствие;
	Заголовки.Вставить("Content-Type", "application/json");
	Заголовки.Вставить("X-Timestamp", Время);
	Заголовки.Вставить("X-Signature", Подпись);
	Запрос = Новый HTTPЗапрос("/api/v1/payments/callback", Заголовки);
	Запрос.УстановитьТелоИзСтроки(Тело, КодировкаТекста.UTF8, ИспользованиеByteOrderMark.НеИспользовать);
	Попытка
		Ответ = Новый HTTPСоединение("pbk.spb.ru", 443,,,, 15, Новый ЗащищенноеСоединениеOpenSSL).ОтправитьДляОбработки(Запрос);
		Если Ответ.КодСостояния <> 200 Тогда
			ЗаписьЖурналаРегистрации("ИНФОТЕХ.ОплатыСайт", УровеньЖурналаРегистрации.Ошибка,, Документ, Ответ.ПолучитьТелоКакСтроку());
		КонецЕсли;
	Исключение
		ЗаписьЖурналаРегистрации("ИНФОТЕХ.ОплатыСайт", УровеньЖурналаРегистрации.Ошибка,, Документ, ОписаниеОшибки());
	КонецПопытки;
КонецПроцедуры

// HMAC по RFC 2104 на ХешированиеДанных (SHA256, блок 64 байта)
Функция HMAC_SHA256(Знач Ключ, Данные)
	Если Ключ.Размер() > 64 Тогда Ключ = Хеш(Ключ); КонецЕсли;
	БуферКлюча = Новый БуферДвоичныхДанных(64);
	БуферКлюча.Записать(0, ПолучитьБуферДвоичныхДанныхИзДвоичныхДанных(Ключ));
	ipad = Новый БуферДвоичныхДанных(64); opad = Новый БуферДвоичныхДанных(64);
	Для i = 0 По 63 Цикл
		ipad.Установить(i, ПобитовоеИсключительноеИли(БуферКлюча.Получить(i), 54));
		opad.Установить(i, ПобитовоеИсключительноеИли(БуферКлюча.Получить(i), 92));
	КонецЦикла;
	Внутр = Хеш(Склеить(ПолучитьДвоичныеДанныеИзБуфераДвоичныхДанных(ipad), Данные));
	Возврат Хеш(Склеить(ПолучитьДвоичныеДанныеИзБуфераДвоичныхДанных(opad), Внутр));
КонецФункции

Функция Хеш(Данные)
	Х = Новый ХешированиеДанных(ХешФункция.SHA256); Х.Добавить(Данные); Возврат Х.ХешСумма;
КонецФункции

Функция Склеить(А, Б)
	Массив = Новый Массив; Массив.Добавить(А); Массив.Добавить(Б);
	Возврат СоединитьДвоичныеДанные(Массив);   // глобальный метод платформы 8.3.9+
КонецФункции
```

Названия реквизитов (`РасшифровкаПлатежа`, `НомерВходящегоДокумента`, вид операции) сверьте с вашей редакцией УНФ.
Проверочный вектор: секрет `test`, время `1700000000`, тело `{}` → подпись `91dff526ea91625b2c0961f314dff62fe9b019efa5f0994fae77116a93f588b3`.

Сайт при повторной отправке того же поступления ответит `duplicate`, поэтому повторы после сетевых ошибок безопасны.

## Контур В: выписка вручную

СберБизнес → Счета → Выписка → период → «Экспорт» → формат **1С (1CClientBankExchange)**, файл .txt.
В /lk/admin/ откройте «Оплаты Сбербанк» → «Загрузить и разнести». Берутся только поступления на ИНН 7811653356.
Повторная загрузка той же выписки дублей не создаёт.
